Design Improvement: Agent Simulator

Date: 2026-05-15  ·  Screen: Main workspace
TL;DR: The biggest opportunity is space reclamation: the bottom Task Chat panel defaults to 280px and the canvas is the primary stage. Collapsing it by default, plus surfacing Smart Mode as a visible input mode rather than a hidden toggle, would immediately make the app feel more powerful and intentional.

Improvement Ideas

⭐ 1. Collapse Bottom Panel by Default

Set height: 42px as the default state for .bottom-panel on load. Show the Task Chat title + agent chips, but start body hidden. Users expand on demand.

The current 280px default buries the canvas — the actual simulation stage — before any agent interaction happens. This is the single change with the highest visual impact for zero effort.

Vibe-kanban — Four-panel workspace with collapsible bottom panel; chat stays accessible without dominating the layout [Lazyweb]

Implementation: In script.js, add bottomPanel.classList.add('collapsed') during app init (before WebSocket connects).

2. Make Smart Mode a First-Class Input Mode

Replace the tiny <label class="smart-toggle"> in the panel header with a visible mode pill that lives inside the command input bar. Two states: [$ CMD] vs [✦ SMART]. When Smart is active, tint the prompt accent color and change placeholder text to "Ask in natural language…"

Smart Mode is the AI superpower of the app, but it's a hidden toggle most users will never notice. Making it visible signals that AI is a first-class citizen.

3. Visual Hierarchy in Quick-Command Grid

The 6 quick-grid buttons are visually identical. Split them into tiers:

  • Primary actions (mutate agent state): All→Center, Stop All → accent-tinted background + border
  • Utility/info: Status, History, Help → current muted style (fine)
  • Destructive: Reset → subtle red tint on hover (var(--err-bg) + var(--err) text)

4. In-App Keyboard Shortcut Strip

Add a single-line hint strip below the command input, visible on focus. Shows: Tab → autocomplete · ↑↓ → history · / → focus · Ctrl+L → clear log

The app has excellent keyboard support but it's completely undiscoverable in-app. It only appears in the README. Power features users don't know about are wasted.

Inspired by

Implementation:

  font-size: 10px; color: var(--text-3);
  padding: 0 12px 8px; font-family: var(--mono);
  opacity: 0; transition: opacity .2s;
}
.cmd-panel:focus-within .cmd-hints { opacity: 1; }

Add one line to index.html inside .cmd-panel: <div class="cmd-hints">Tab → autocomplete · ↑↓ history · / focus · Ctrl+L clear</div>

What's Working

  • Design system is excellent — The token system (--bg, --surface, --accent, etc.) is consistent and professional. The Raycast-inspired charcoal theme is polished.
  • Chain-of-thought display — The bp-cot-thought left-border + bp-cot-observation green indicators are a standout UX detail for agent reasoning. Don't change this.
  • Agent card delete pattern — Delete button appears only on hover, red-tinted. Correct interaction model for destructive actions.
  • Canvas toolbar separation — Grouping select/drag tools separately from record/playback in the same bar is clean and logical.
  • MCP preset pill "added" state — Green border + no pointer-events gives instant confirmation without a modal. Excellent micro-interaction.

Design Improvement: Canvas Entities

Date: 2026-05-15  ·  Screen: Canvas — agent icons & table objects
TL;DR: Three ready-to-implement variants for agent icons and table objects rendered on the canvas. Variant A (Glowing Avatar) is the highest-impact change — agents get an avatar layer with a person silhouette, and objects get a colored header stripe for instant type recognition. All three slot directly into the existing drawAgent() / drawObject() functions.

Choose a Variant

Each canvas below is live — rendered with actual Canvas 2D API calls, exactly as it will appear in the app.

⭐ Recommended
A — Glowing Avatar
Warm · human · Notion-ish
Agent: Colored outer rim (r=17) + dark center (r=11) + person silhouette icon. Bigger initial letter replaces "AGENT1" text.

Object: Tinted header strip (top 28%), type emoji left-aligned, label in lower portion, thicker border (2px), r=10.

Keeps the glow shadow, just restructures depth so agents look like avatars, not circles. Medium effort
Variant B
B — Geometric Badge
Clean · numeric · jersey
Agent: Radial gradient fill + bold 2.5px ring, always visible. Large index number (1, 2, 3…) instead of text. State arc segment on lower-right edge.

Object: 3px left accent stripe, label left-aligned. Type abbreviation badge top-right. No glow — cleaner, flat.

Minimal code delta. The easiest of the three to implement. Low effort
Variant C
C — Dot Grid
Geometric · techy · blueprint
Agent: Octagon shape (8-sided polygon). Dark fill, colored outline. 3×3 dot grid inside — center dot state-colored.

Object: Corner fold (top-right squared), dotted top border divider, task text below the divider line. No separate chip.

Most visually distinct from current. Great for a "simulation / blueprint" aesthetic. Medium effort

What's Working (Keep These)

  • Per-agent colors — a.color per agent is the strongest orientation cue on the canvas. Every variant preserves it.
  • Speech bubble above agent — Dark #2C2C32 bubble with colored border tail is excellent for readability. Unchanged in all three.
  • Animated moving ring — The sin-pulse ring on moving state reads instantly without any label. Keep it in A and B.
  • OBJ_STYLE type colors — Purple/table, cyan/computer, amber/chair color language already works. All variants build on it.
  • Agents-here badge — The top-right circle with count is simple and functional. A upgrades it to a pill; B and C keep it as-is.
